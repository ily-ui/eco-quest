# 🌍 ЭкоКвест

Игра-сайт по экологии для школьников: основная ветка + побочные ветки, XP, серии дней, достижения и сертификат «Эко-герой».

## База данных (чтобы прогресс не пропадал)

Данные хранятся во внешней бесплатной PostgreSQL, а не в файле на сервере.

**Neon (проще всего):** neon.tech → регистрация → Create project → на странице проекта скопируй строку подключения (начинается с `postgresql://`).

**Supabase:** Project → кнопка Connect → выбери **Session pooler** (прямое подключение не работает на хостингах без IPv6) и скопируй строку, заменив `[YOUR-PASSWORD]` на пароль базы.

Таблицы создаются автоматически при первом запуске.

## Запуск на своём компьютере (Windows)

```
npm install
set DATABASE_URL=сюда_строка_подключения
npm start
```
Открой http://localhost:3000

## Хостинг (Render и др.)

В настройках сервиса → **Environment** → добавь переменную `DATABASE_URL` со строкой подключения. Build Command: `npm install`, Start Command: `npm start`. Остальное необязательно: `DAILY_CAP` (лимит XP в день, по умолчанию 80), `PORT`.

## Как устроено

- Аккаунты: логин + пароль (bcrypt), сессия в HttpOnly-cookie, логин уникален без учёта регистра.
- Вопросы: блок «КОНТЕНТ» в начале `server.js` (хелперы `C`, `S`, `M`, `K`).
- Защита от списывания: ответы не уходят на клиент, случайный порядок, таймер на вопрос, сброс при уходе со страницы и кулдаун 3 минуты.
- Растягивание игры: 5 уровней в каждом задании, лимит XP в день, тяжёлые достижения (серия 30 дней, 1000 XP, мастер всех заданий).
