# 🌍 ЭкоКвест

Игра-сайт по экологии для школьников: основная ветка + побочные ветки (Вода, Отходы, Энергия, Биоразнообразие), XP, серии дней, достижения и сертификат «Эко-герой», который ученик показывает учителю с экрана.

## Запуск

Нужен Node.js 18+ и интернет у браузера (Tailwind подключается с CDN).

```bash
cd eco-quest
npm install
npm start
```

Откройте http://localhost:3000, зарегистрируйтесь и играйте. Данные лежат в файле `eco.db` (SQLite) рядом с сервером.

Переменные окружения: `PORT` (по умолчанию 3000), `DAILY_CAP` (лимит XP в день, по умолчанию 80), `DB` (путь к файлу БД).

Для школы: запустите на любом сервере с Node.js (Render, Railway, VPS) и держите `eco.db` на постоянном диске, иначе прогресс пропадёт при перезапуске.

## Как устроено

- **Аккаунты:** логин + пароль (bcrypt), сессия в HttpOnly-cookie. Логин уникален без учёта регистра: один аккаунт = один прогресс. Без email, кодов и реестров.
- **Задания:** 8 заданий (4 в основной ветке, по одному в побочных), у каждого 5 уровней мастерства. Форматы: выбор ответа, правда/ложь, найди лишнее, сортировка (перетаскивание или тап), соедини пары, калькулятор следа, сценарий с последствиями.
- **Новые вопросы:** блок «КОНТЕНТ» в начале `server.js` (хелперы `C`, `S`, `M`, `K`).

## Защита от списывания

- Правильные ответы **не уходят на клиент**, всё проверяется на сервере.
- Вопросы и варианты каждый раз в случайном порядке, показываются по одному, назад нельзя.
- Таймер на каждый вопрос (с ростом уровня короче), сервер проверяет время сам.
- Уход со страницы (`visibilitychange`, `blur`, кнопка «назад», закрытие вкладки) сбрасывает попытку и включает кулдаун 3 минуты. Копирование и контекстное меню в задании отключены.
- Серьёзных ошибок на уровнях 1–2 допускается одна, с 3 уровня ни одной.

## Искусственное растягивание игры

- Уровни открываются строго по очереди, на проваленное задание кулдаун 3 минуты.
- **Лимит 80 XP в день:** после него новые попытки закрыты до завтра. Полный набор XP (≈1400) это минимум 2–3 недели.
- Тяжёлые достижения: «Океан знаний» (1000 XP), серии 14 и 30 дней, 25 безупречных уровней, «Мастер» по каждому заданию, «Эко-герой» (вся основная ветка на 5 уровней) и «Легенда планеты» (всё сразу, минимум 30 дней).

## Ограничения

Браузерная защита не остановит ученика с телефоном в другой руке. Её сдерживают таймеры, серверная проверка и лимит в день. Подбирайте `DAILY_CAP` под вашу задумку.
